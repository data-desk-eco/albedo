Hi Louis, thank you for sharing the first version of the map - it’s great to see results so quickly! Here are some thoughts and questions from my colleagues about the map: 
1. Traffic dynamics over time: If data for other years is available, it would be great if users could explore traffic dynamics on the map. It can be static in base version but it would be great if somehow this opportunity to track the changes over time is available. 
2. Filtering options: Is it possible to include filters by vessel type, vessel age, and type of fuel burnt? Is it possible to make a menu like the one you did here? https://tools.datadesk.eco/nsr-map/?imo=8408985 
3. Protected areas: Currently, points where vessels intersect with protected areas are labeled as "incursion”, right? Depending on specific reserves or protected zones, entering certain waters might not actually be prohibited. Would it be possible to use a more neutral term such as "crossing" to better reflect "intersection”? Also there are some points located on land (e.g., Kola Peninsula), not water - is it correct? 
4. Design - maybe the current color scheme could be adjusted for a bit more clarity and realism. We can give you our brandbook colours, if you’d like but it’s optional, - the overall suggestion is maybe to make the map a bit less schematic and add some geographic details, like a map labels, legend, and some hover information - for example, whether dense activity represents multiple trips by one vessel or many vessels at once, and for which time period.
5. Geographical focus: the map currently includes areas beyond NSR region, would it be possible to limit the map to the seas relating to NSR to jeep focus on the Arctic?
6. Seasonality and ice coverage: Additional idea (optional) - can ice coverage data be included? This affects vessel activity, as certain areas may be impassable at different times of year. Also just to double check (this intersects with point 1) - the current snapshot is cumulative or does it represent a specific time period?
7. Language versions: We may also need a Russian version of the map, since most labels are currently in English. We will do the translation ourselves, I’d like to check if it’s possible in general.
